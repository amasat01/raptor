raptor.conformance
===================

The interop certification declaration and its reusable matrix-hygiene
scanners. ``interop`` holds the row catalogue (``ROWS``), the certified vs.
roadmap framework sets, and the completeness/skip-freedom scanners every
owning repository's test suite calls. ``doc_includes`` is a
non-Sphinx-warning-dependent checker for ``include``/``literalinclude``
targets, reused by every repository in the family.

See :doc:`../interop_protocols` for the human-readable certification matrix
this module's ``ROWS`` declares.
